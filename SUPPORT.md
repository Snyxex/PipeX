# Support

Start with the [README](README.md) and [enterprise guide](docs/enterprise.md) for examples, limits and security boundaries.

For ordinary defects, use the [bug report form](.github/ISSUE_TEMPLATE/bug_report.yml). For ideas or feature requests, use the [feature request form](.github/ISSUE_TEMPLATE/feature_request.yml). Include the PipeX version or commit, Node.js version, operating system, a minimal reproduction and sanitized logs.

Community help and maintenance are provided on a best-effort basis; no response-time guarantee or commercial support contract is offered.

**Security vulnerabilities must not be reported in public issues.** Follow [SECURITY.md](SECURITY.md) and coordinate privately. Do not upload credentials, real user data or production logs.
