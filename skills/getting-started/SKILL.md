# getting started

Use this skill when the task matches the description.

## Instructions
Use Node >=20.19.0 and ESM. Check README and package.json: npm registry publication is not yet established; repository installation is documented. Import DataEngine and plugins from 'pipex'. Create an engine, configure plugins before running operations, and verify binary.run/undo on trusted inputs. Never invent default configuration or claim CommonJS support. Confirm the installed version's exports.

## Verification
Inspect the checked-out source and relevant tests before proposing code. Prefer the public API, document assumptions, and do not claim tests passed unless executed.
