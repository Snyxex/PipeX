# PipeX Dokumentation

Willkommen bei der PipeX Dokumentation. Hier finden Sie alle Informationen zur Verwendung und Erweiterung von PipeX.

## Übersicht

PipeX ist ein leichtgewichtiges, modulares Daten-Transformations-Framework, das eine einheitliche Stream-basierte Architektur für die Verkettung von Datenverarbeitungs-Plugins bietet.
